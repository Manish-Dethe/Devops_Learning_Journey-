# Linux Project 4: System Monitoring Script

## Objective
The goal of this project is to monitor system health using a shell script and generate a report containing important server information.

## What I Did
* Created a shell script (`system_monitor.sh`)
* Automated system monitoring tasks
* Displayed memory usage, disk usage, CPU information, and system uptime
* Generated a health report file automatically

## Features
* Displays current date and time
* Shows logged-in user
* Displays system uptime
* Shows memory usage
* Displays disk usage
* Shows CPU information
* Saves report to `system_report.txt`

## What I Learned
* System monitoring using Linux commands
* Shell scripting automation
* Using commands like `free`, `df`, `uptime`, and `lscpu`
* Generating automated system reports

## Project Structure
* `system_monitor.sh` → monitoring automation script
* `system_report.txt` → generated system health report

## Commands Used
* `date`
* `whoami`
* `uptime`
* `free -m`
* `df -h`
* `lscpu`
* `chmod +x`

## Conclusion
This project helped me understand how DevOps engineers monitor Linux servers and automate system health reporting using shell scripting.
